# Local fonts

## Manrope

`manrope-variable.ttf` is the unmodified variable font from
[Google Fonts](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope),
revision `b31870aff700ab7a1d74fa0c6887d95beb9e0037`, source path `ofl/manrope/Manrope[wght].ttf`.
Its weight axis spans 200–800. The upstream license and font log are included as `OFL-Manrope.txt`
and `FONTLOG-Manrope.txt` (trailing whitespace normalized).

SHA-256: `3ae11c49db0455a3cc33e37d380f20fdb8c7f8b41dc07625c177e3d87a9d6ae6`.

## Geist

Unmodified variable WOFF2 font from the official
[Geist repository](https://github.com/vercel/geist-font), revision
`10dc7658f13c38a474cde201bb09a4617267545b`.

- `geist-mono.woff2`: `fonts/GeistMono/webfonts/GeistMono[wght].woff2`

Geist uses the SIL Open Font License 1.1, included in `OFL.txt`. All fonts are served from this
website's own origin with CSS font loading; no font service or application dependency is needed.
