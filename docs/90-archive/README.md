# Archive

Pre-1.0 product documents, kept as history rather than deleted.

These describe Persist OS as it was designed and built, including the preset system retired in 1.0
([ADR-0007](../adrs/ADR-0007-minimal-by-default-repository-memory.md)). Between them they carry 91
references to presets and a build plan that has since been executed.

They are accurate about what was intended at the time. They are not accurate about the product.

**For the current product, read [`docs/00-product/PRODUCT.md`](../00-product/PRODUCT.md).**

| Document            | What it was                                               |
| ------------------- | --------------------------------------------------------- |
| `PRD.md`            | The original product requirements, through the preset era |
| `BRD.md`            | The business case and market framing                      |
| `BUILD_PRIORITY.md` | The P0–P15 build sequence, now complete through P13       |

Nothing here is source of truth. Doctor does not read this directory.
